# ◈ BudgetCare

A responsive personal budget tracker built with **HTML, CSS and vanilla JavaScript**. No backend or dependencies needed.

## Features
- Track income, expenses and available balance
- Add, filter and delete transactions
- Categorize spending
- Set a monthly budget and see spending progress
- Data persists using browser `localStorage`
- Responsive interface and Botswana pula (BWP) currency

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages
1. Push the files to a public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then `main` and `/ (root)`.
4. Save and wait for your GitHub Pages URL to appear.

## Tech stack
HTML5 · CSS3 · JavaScript (ES6+) · localStorage

## Privacy and limitations
Data stays in the browser on the current device; it is not synced or backed up. Clearing browser storage removes it. This is a portfolio demo, not a bank-connected finance service. The monthly budget is a single limit applied to the current month.
